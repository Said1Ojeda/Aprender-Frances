# Allez!

Francés básico desde cero, pensado para quien habla español. Lecciones cortas, sin cuenta y sin anuncios, directo en el navegador.

## Qué trae

- Lecciones del nivel A1: saludos, números, colores, familia, comida, los verbos *être* y *avoir*, frases para viajar y falsos amigos
- Ejercicios para reconocer palabras, traducir y escribir en francés
- Un tip por unidad con lo que más confunde a un hispanohablante

## Correrlo en tu compu

Para usarla, descarga el repo y abre `index.html`. El `js/` ya viene compilado.

Para modificarla necesitas [Node.js](https://nodejs.org):

```
npm install
npm run watch
```

El código está en `src/` en TypeScript y se compila a `js/`.
